Phụ đề song ngữ tự căn chỉnh với video

Nhập phụ đề gốc và tiếng Việt, đồng bộ với video, bấm từng câu để tua lại, xuất script song ngữ dạng Word tối ưu giấy A4 và nhập lại chính file Word đó.

1. Phụ đề ngôn ngữ gốc

Hỗ trợ .vtt, .srt và .txt có timestamp. File gốc cần có thời gian để đồng bộ video.

Chưa chọn file.

2. Phụ đề tiếng Việt

Hỗ trợ .vtt, .srt, .txt có timestamp hoặc TXT thuần văn bản, mỗi câu một dòng.

Chưa chọn file.

3. Video trên máy tính

Video chỉ mở trong trình duyệt, không tải lên mạng. MP4 H.264/AAC và WebM thường tương thích tốt nhất.

Chưa chọn video.

4. Link YouTube — tùy chọn

Dán link đầy đủ, link rút gọn youtu.be hoặc chỉ mã video.

5. Script Word song ngữ

Nút “Tải script Word” tạo bảng DOCX hai cột từ các câu hoàn chỉnh mà ứng dụng đã khôi phục, chỉ giữ hàng có đủ câu gốc và tiếng Việt. Nút “Nhập script Word” đọc lại file DOCX đã xuất, kể cả sau khi bạn chỉnh sửa nội dung trong Word.

Chưa nhập file Word.
